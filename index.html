🎮 What is chaos-link?

chaos-link connects your CS2 game to a web interface that your friends can open on their phones. Once connected, they can send real-time effects and punishments directly into your game. Think of it as a live, interactive chaos button — but controlled by your friends. It’s built for Windows, easy to set up, and requires no coding skills.

Whether you’re hosting a game night, a stream, or just want to make your solo match more unpredictable, chaos-link turns every round into a social event.

🔥 Key features

  • Real-time chaos – Friends trigger effects instantly via their phones. No delays, no setup.
  • Works with CS2 – Designed specifically for Counter-Strike 2. Effects include screen shakes, key jams, view bobbing, sound spam, and more.
  • Phone control – Friends join a web session on their phone. No app needed. Just a browser.
  • WebSocket-powered – Fast, reliable communication between your PC and your friends’ devices.
  • AutoHotkey integration – Effects are applied via AutoHotkey scripts, making them lightweight and compatible.
  • Party game mode – Perfect for 2–10+ players. The more friends, the more chaos.
  • No programming required – Download, run, and share the link. That’s it.

🚀 Getting started

Follow these simple steps to get chaos-link running on your Windows PC. You do not need to install any extra tools, compilers, or frameworks.

  1. Download the application – Visit this link to download the application. The file is a ready-to-run package for Windows.
  2. Run the downloaded file – Double-click the file you downloaded. Windows may show a security prompt; click “Run anyway” if you trust the source (it’s safe).
  3. Wait for the server to start – A small window or terminal will appear. It shows a local address (like http://192.168.x.x:5000). Keep this window open.

❓ Frequently asked questions

Do I need to install anything else?

No. The download includes everything needed. AutoHotkey, WebSocket server, and the web interface are all bundled.

Can I use this with other games?

chaos-link is optimized for CS2. While some effects may work with other games, it is not guaranteed. We recommend using it only with CS2 for the best experience.

My friends can’t connect. What should I do?

Make sure all devices are on the same Wi-Fi network. Check that the terminal window is still running. Try disabling your firewall temporarily or adding an exception for chaos-link.

Is this safe?

Yes. chaos-link does not collect any data, does not require an internet connection, and runs entirely locally. The source code is open for review.

How do I stop the chaos?

Close the chaos-link window or press Ctrl+C in the terminal. Friends will lose access immediately.
